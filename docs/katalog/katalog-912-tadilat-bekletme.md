# #76 kabul düzeltmesi: Bağcılar / Sancaktepe

Eylül sipariş kaydı yalnızca geçmiş faaliyeti kanıtlar. Bu nedenle `burger-yiyelim-sancaktepe-bagcilar` yayımlanacak katalogdan çıkarıldı; yeniden açılış doğrudan doğrulanınca ayrı değerlendirilir. Kabul sonucu: canlı tabana göre **+20**, **912 toplam**, **877 aktif**, **752 aktif restoran**. Yerel aday; yayına alındığı anlamına gelmez.
