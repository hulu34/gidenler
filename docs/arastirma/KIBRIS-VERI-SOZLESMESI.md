# Gidenler → YorumS: yerel Kıbrıs pilot sözleşmesi

Bu, tek kaynaklı MasaMoro fixture'ı için **izin bekleyen Preview hazırlık sözleşmesidir**. Yayın, gerçek import, DB migrasyonu, mevcut hesapların ortaklaştırılması veya diğer adayların kabulü değildir. YorumS depoları değiştirilmedi.

1. **Bölge:** ham kayıtta ve entity/UI'da `bolge: { alan: "kibris", bolge: "lefkosa", kesim: "guney" }`. Alan isimleri ve slug'lar mevcut YorumS `lib/bolge.ts` ile aynı. Kesim bu sözleşmede açıkça zorunlu; bölünmüş Lefkoşa için tahmin edilmez. Bölge adı İstanbul district'ine yazılmaz; `district: ""`, şehir görünümü `Lefkoşa`. Görünür konum `Lefkoşa (güney) · Kıbrıs`. Geçersiz/çelişkili bölge İstanbul'a düşürülmez.
2. **Kimlik:** araştırma `manifestId = kibris/masamoro` ve ham kayıtta `researchId = kibris/masamoro`; yerel modelde sabit `slug = masamoro-lefkosa-guney-kibris`, `ref = isletme/masamoro-lefkosa-guney-kibris`, entity id `ent.r.masamoro-lefkosa-guney-kibris`. İşletme ref'i mevcut Gidenler namespace'ini kullanır; sahte OSM ref üretilmez. Bu öneri henüz Production kimlik tahsisi değildir. İsim/konum yakınlığı ile başka işletme birleştirilmez.
3. **Bilinmeyen alanlar:** fixture girişinde `lat/lng/phone: null`; Gidenler bölgesel normalleştiricisi bunları **eksik** alana dönüştürür. 0/0, tek eksen, uydurma koordinat veya İstanbul ilçesi kabul edilmez. Bu pilotta geometri/osmRef/location kabulü yoktur. Entity `location.geo` ve telefon bulunmaz; iframe/pin/OSM atfı üretilmez. Kaynaklı sokak adresi korunur.
4. **Kanıt:** `sourceKind`, `sourceUrl`, özgün manifest id bağlantısı, tarih ve ham `provenance` kaybolmamalı. Gidenler ham normal kaynak birleştiricisi kanıt listesini korur; istemci UI yalnız gerekli kaynak kimliği/konumu alır. Güncel faaliyet, koordinat, puan veya telefon doğrulanmış gibi eklenmez.
5. **Tekrar/çakışma:** aynı ref/slug + aynı normalize içerik tek kimliktir; JSON alan sırası önem taşımaz. Farklı içerik veya eski İstanbul kimliğiyle çakışma açık hata verir, eski kayıt ezilmez. Bu yalnız kaynak birleştirme kabulüdür; YorumS import/profile sync tekrarı ve gerçek DB replay ayrıca kanıtlanmalıdır.
6. **Görünürlük:** varsayılan kapalı. Yerel development/test + `NEXT_PUBLIC_KIBRIS_PILOT=true` desteklenir. Ek olarak yalnız Gidenler `inceleme/masamoro-preview-kabul-v1` dalının gerçek `VERCEL_ENV=preview` ortamında, açık pilot ve `NEXT_PUBLIC_KIBRIS_PREVIEW_CONTRACT=masamoro-v1` ile sınırlı Preview hazırlanabilir. Sunucu platform/dal/değişmez host kontrolünü yapar; istemci yalnız sunucunun aynı host için verdiği başlangıç bağlamıyla kaydı yükler. Production, bilinmeyen ortam/dal, kapalı/tanımsız bayrak, yanlış host ve bağlamsız istemci kapalıdır. Gerçek Preview kaynağı veya ayarı henüz oluşturulmadı. RY/YY kendi ayrı hedef dal/bayrak sözleşmesini ve aynı Production ret kuralını korur.
7. **Kapsam:** kamu JSON-LD/sitemap yok, metadata noindex. Google/Excel ve Sor kapsamı İstanbul olarak kalır. Gidenler'in mevcut DB seed/append yolu bölgesel kaydı DB'ye dokunmadan reddeder; bölgesel DB aktarımı bu sözleşmenin kabul edilmiş parçası değildir. 892 kaynak/857 aktif İstanbul ve hesap/deneyimler değişmez; üç ürünün hesapları/veritabanları ayrıdır.
8. **Devir kabulü:** Gidenler `scripts/kibris-pilot-export.ts` normal veri yolundan yalnız tek normalize pilot kaydı ve gerçek kaynak commit SHA'sını JSON olarak verir; yerelde kirli çalışma ağacını reddeder.  YorumS sorumlusu normal importer → profile sync → arama/detail yolunda aynı fixture ile bölge/kimlik/boş geometri, kapalı pilot, eski İstanbul kayıtlarının korunması ve tekrar davranışını sınamalı.
